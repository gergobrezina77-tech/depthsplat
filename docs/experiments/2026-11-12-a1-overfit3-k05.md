# A1 Experiment: Overfit 3 Scenes, Fixed Views, Fixed Budget k=0.5

Date: 2026-11-12. Ticket: A1-14. Run: `outputs/approach1/overfit3_k05`.
Follows [the 1-scene run](2026-11-12-a1-overfit1-k05.md); same loss, lr and trainable part.

## 1. Setup

| Setting | `overfit1_k05` | `overfit3_k05` |
|---|---|---|
| Scenes | `41b80c5fb43019e5` | `41b80c5fb43019e5`, `c356b5fd63ca4228`, `3fe0de697d29ee3b` |
| Views | fixed per scene (index file) | fixed per scene (`assets/evaluation_index_a1_overfit3.json`) |
| Budget / loss | k=0.5, `L_full + L_prefix`, linear | same |
| Batch | 1 | 3 = all scenes every step |
| `train_times_per_scene` | 1000 | 1 (1000 would repeat each scene 1000 times in a row) |
| Validation | 41b80c, iterator kept alive | 41b80c, worker restarted every check (`persistent_workers=false`, `shuffle_val=false`) |

Command: `bash scripts/a1_overfit3_k05.sh`. 3000 steps, ~45 min, ~5.3 GB.
Smoke check with `lr=0`: `train/psnr_full` and `train/psnr_prefix` equal the frozen 3-scene means
(28.56 / 13.72 dB), so every batch holds all 3 scenes.

Scene choice: 41b80c to compare with the 1-scene run, c356 because `overfit5` failed on it, 3fe0 as
a typical scene.

## 2. Results

Eval of the step-3000 checkpoint, per scene (`scripts/a1_eval.sh`, PSNR dB / LPIPS). Kept count
equals `floor(k x 131072)` in every row.

| `k` | 41b80c frozen | 41b80c tuned | c356 frozen | c356 tuned | 3fe0 frozen | 3fe0 tuned |
|---|---|---|---|---|---|---|
| 1.0 | 30.32 / 0.080 | **31.47** / 0.078 | 28.23 / 0.110 | **26.10** / 0.128 | 27.13 / 0.086 | **29.23** / 0.078 |
| 0.5 | 13.53 / 0.365 | **27.91** / 0.124 | 16.44 / 0.303 | **23.55** / 0.164 | 11.18 / 0.463 | **26.09** / 0.120 |
| 0.25 | 6.33 | 15.83 | 8.85 | 9.85 | 6.76 | 14.10 |
| 0.1 | 4.65 | 11.51 | 6.97 | 7.09 | 4.90 | 10.25 |

3-scene mean: k=0.5 13.72 → 25.85 dB, k=1 28.56 → 28.93 dB.

Training curves (means over sixths of the run):

- `loss/prefix`: 0.0211 → 0.0138 → 0.0114 → 0.0103 → 0.0098 → 0.0097.
- `loss/full`: 0.0077 → 0.0062. It first rises from 0.0061 (steps 0-500), then recovers.
- `train/psnr_prefix`: 21.5 → 25.8 dB; `train/psnr_full`: 27.8 → 28.9 dB.
- `val/psnr@0.5` on 41b80c: 23.05 (step 99), 26.60 (999), 27.91 (2999). The 1-scene run ended at
  28.81 dB, so sharing the head with two more scenes costs 0.9 dB on this scene.

## 3. Mechanism (`src/approach1/analyze.py`, one run per scene)

Swap test at k=0.5 (PSNR dB): one model's parameters, cut by either model's opacity ranking.

| Scene | Frozen / frozen | Frozen params / tuned rank | Tuned params / frozen rank | Tuned / tuned | Tuned, random cut |
|---|---|---|---|---|---|
| 41b80c | 13.53 | 15.69 | 18.60 | **27.91** | 26.20 |
| c356 | 16.44 | 14.50 | 19.89 | **23.55** | 20.79 |
| 3fe0 | 11.18 | 13.67 | 14.61 | **26.09** | 26.38 |

| Scene | Top-50% shared with frozen | Kept share view 0 / 1 (frozen → tuned) | Median size kept / dropped (tuned) |
|---|---|---|---|
| 41b80c | 87.9% | 52/48 → 54/46 | 0.0217 / 0.0250 |
| c356 | 82.4% | 29/71 → 20/80 | 0.0259 / 0.0130 |
| 3fe0 | 87.4% | 55/45 → 61/39 | 0.0173 / 0.0268 |

Findings:

- **The pipeline overfits 3 scenes at once.** k=0.5 rises by +12.1 dB on average (+7.1 to +14.9
  per scene). Same pattern as the 1-scene run: only ranking and parameters together give the gain.
- **The full set holds on average (+0.4 dB) but not on c356 (-2.1 dB).** The 56k head now has to
  serve three scenes at both budgets, and c356 pays for it.
- **c356 is solved differently.** Its kept Gaussians are 2x larger than the dropped ones (the other
  two scenes: kept smaller than dropped), and the tuned ranking alone makes the frozen render
  worse. This looks like the `overfit5` failure mode (big Gaussians filling holes), on the same
  scene where `overfit5` failed.
- **Opacity cut vs. random cut:** better on 41b80c (+1.7 dB) and c356 (+2.8 dB), equal on 3fe0
  (-0.3 dB). The ranking advantage is smaller than in the 1-scene run (+3.1 dB).
- **Only k=0.5 is learned.** k=0.25 and below stay far from usable (10-16 dB), as in the 1-scene
  run.

Gate G1c passes: `train/psnr_prefix` rises steadily from 13.72 to 25.85 dB, and `val/psnr@0.5` on
41b80c ends at 27.91 dB (1-scene: 28.81 dB).

## 4. Limits

- 3 scenes, fixed views: still memorization.
- `val/psnr@k` covers only 41b80c; the per-scene table comes from the final checkpoint only.
